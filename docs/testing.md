# Тестування та критерії приймання

Запуск: `python -m pytest -v`.

| Клас | Перевірки | Очікуваний результат |
|---|---|---|
| AES-128/192/256 GCM і CBC-HMAC | Порожній / звичайний / бінарний текст | Roundtrip дорівнює оригіналу |
| AES integrity | Зміна шифротексту, заголовка, чужий ключ | Authentication failure, plaintext-файл не створюється |
| KeyStore | Збереження під пароль, 0600, ротація | Старі версії ключів доступні, нові згенеровані |
| RSA-OAEP | 2048-bit, маленький текст | Після decrypt — вихідний текст |
| RSA-PSS | Підпис / підміна тексту | VALID / INVALID |
| Invalid PEM | Некоректний PEM | Контрольоване виключення |
| Hybrid | Великий файл, підміна, інший отримувач | Roundtrip / error / error |
| CLI | Вхід через файл і `--text`, JSONL log | Команди працюють, секрети не журналюються |
| Benchmark | AES sizes, GCM/CBC, RSA bits | Створено CSV, MD, JSON із фактично виміряними значеннями |

Невірний пароль для AES та RSA має закінчуватися **помилкою**, але без виведення приватного ключа. Окрема перевірка має підтвердити, що ciphertext після зміни байта більше не розшифровується.
